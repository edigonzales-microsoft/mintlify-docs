XBOX GDK titles render through **DirectX 12 Ultimate** with platform-specific extensions for XBOX Series X|S.

## Core features

- **Mesh shaders** — amplification \+ mesh stages replacing the legacy geometry pipeline. See [Mesh shaders](/gdk/mesh-shaders).
- **Variable Rate Shading (VRS)** — per-region pixel shader rate control. See [VRS](/gdk/vrs).
- **Hardware raytracing** — DXR 1.1 on XBOX Series X|S. See [Raytracing](/gdk/raytracing).
- **Sampler Feedback Streaming (SFS)** — GPU-reported texture residency. See [Sampler feedback](/gdk/sampler-feedback).
- **DirectStorage** — NVMe-class asset streaming. See [DirectStorage](/gdk/directstorage).
- **XBOX Texture Compressor (XBTC)** — BCPack and Zlib GPU decompression. See [Texture compressor](/gdk/xbox-texture-compressor).
