XBOX Series X|S exposes a unified GPU \+ CPU memory model with strict per-title budgets. Manage memory explicitly to hit those budgets.

## Key concepts

- **Title budget** — fixed per generation (Series X, Series S, XBOX One).
- **GPU upload heap vs default heap** — choose carefully; default heaps are GPU-local and faster.
- **D3D12 placed resources** — explicit heap management.
- **Memory hooks** — the GDK accepts user-provided memory allocators for XAsync, XCurl, libHttpClient, XSAPI, and PlayFab.

## Best practices

- Pre-budget per subsystem (rendering, audio, gameplay, networking, scripting).
- Track allocations with PIX events.
- Run with low-memory simulation to verify graceful degradation.
