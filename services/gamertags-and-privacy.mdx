Display user-generated content (gamertags, chat, club names) safely and respect each player's privacy settings.

## Modern gamertags

- Gamertags can include Unicode characters and a numeric suffix (`Player#1234`).
- Use [XSAPI Profile](/reference/xsapi-profile) to fetch the canonical display string.
- Always render the modern gamertag exactly as returned — do not strip the suffix.

## Privacy checks

Before sending invites, voice, text, or sharing UGC, check permissions with [XSAPI Privacy](/reference/xsapi-privacy):

- `XblPrivacyCheckPermissionAsync` — single-permission check.
- `XblPrivacyBatchCheckPermissionAsync` — batch check for many users.

## String verification

Validate user-entered strings (gamertags, clan names, custom presence) against the Microsoft policy and profanity filter with [XSAPI String Verify](/reference/xsapi-string-verify) before display or storage.
