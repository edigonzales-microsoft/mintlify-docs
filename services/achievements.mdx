Design, configure, and unlock XBOX achievements in your GDK title using the XSAPI Achievements API.

## How achievements work

- Achievements are defined in **Partner Center** and tied to your service configuration (SCID).
- Players progress and unlock them via [event-based stats](/reference/xsapi-stats) or direct progress calls.
- Cached, event-driven state is available via the [Achievements Manager](/reference/xsapi-achievements-manager).

## Implement achievements

- Use [`XblAchievements*`](/reference/xsapi-achievements) APIs to read and update progress.
- Use the [Achievements Manager](/reference/xsapi-achievements-manager) when supporting multiple local users.
- Write game events with [`XGameEvent`](/reference/xgameevent) for event-based achievements.
